# 块 021（起始章节：第687章 目标出现 → 第721章 彻底的离别；第689章起为郑应雄第一人称回忆「玉城往事」）

## 本块事件
- 郑英雄追问玉城，地猴透露：自己曾在玉城开赌档、仅两人进过他的场；玉城自定规则，供奉的「神龙」「刑官」其实只是地龙、地牛两只生肖，一旦调离玉城就真的死了；整座城「得了绝症」，只能等它消亡(第687章)。
- 昏迷的齐夏苏醒「变质」：眼白暗灰、瞳孔横长方形、笑容陌生。自称用七十年参透世界答案但计划缺一环、记忆零散，问「文巧云已经死了吗」；断言无人能逃、要带大家在终焉之地生活；提及在每条命脉上插了「针」、燕知春、「天龙也该醒了」。陈俊南怒揍他(第687-688章)。
- 郑英雄摘下报纸王冠向齐夏半跪，称「我来到这里的目标出现了」——他嗅到齐夏身上一闪而过的「神」的气味(第688章)。
- 郑应雄自述：泉州八岁小学生，不堪同桌许家华欺凌，偷饭票栽赃于他；地震中许家华推开他被吊扇刺穿胸口，临终说「我知道」「没关系」(第689-690章)。
- 死后被吊入面试房间：兔/虎/狗三面具主持十分钟氯气游戏，钥匙在井底；大人欲割绳弃孩取钥匙，李思维坚持绑绳；应雄觉醒「灵嗅」，借闻到李思维传来的「想法」破局，全员生还。龙头人发「玉」：十天集五万七千六百颗(第690-693章)。
- 万财组建传销式「大家庭」：拉人、上下线、玉奖励、口号与参拜神龙；他从「地虎」自相残杀游戏独自生还，觉醒「扩音」；魔术师顾禹（「隐匿」）入伙(第694-697章)。
- 首次湮灭：应雄回到地震前一天，向打牌的阿妈道爱、拉许家华逃亡并大喊「对不起」，死前体会自由；清香者保留记忆，回现实约一天半再入局(第698章)。
- 第二轮：万财以应雄为「审查者」拉人建金字塔，据超市；胖哥哥玩「人鸡」游戏后觉醒「惊雷」；顾禹悟出清香须经游戏历练，第九日清香者二十余人；婶婶参拜「神龙」后觉醒，参拜成制度(第699-702章)。
- 顾禹离队（「这个地方不需要感情」），李思维因放不下应雄留下，觉醒「治愈」(第703章)。
- 数年后家庭破千、迁入写字楼：刘飞求应雄谎报清香事发，万财命他与女牛头人玩「拔河」并念出「我要和你赌命」借刀杀人；两次逃跑失败后二人被全天监视(第704-706章)。
- 万财夜谈预言「权力→混乱→崩坏」三时代，称次日凑足玉离开；翌日保险柜被清空——顾禹用听诊器开柜、以「隐匿」藏玉，防人集齐触发「重新开始」；万财被家规公审，李思维揭其借地牛当刑官处决方姐等旧事，应雄下令依家规处决，万财沦为游荡者(第707-708、711章)。
- 顾禹四年后归来，带回五城情报：玉、涡、道三城活跃，两城已灭；集齐即「重新开始」的大骗局；涡城聂北全民皆兵血战生肖，道城钱多多述智将治国、首领文巧云未见。三人定策「英雄时代」，神化应雄；应雄立志「做正确的事」(第709-711章)。
- 应雄闻到道城方向「巨大想法」的召唤：「来找我……无论过去多少年，我都在这里等你」；顾禹述道城「显示屏+铜钟」奇观（自述「我听到了回响」；道城称能力者「回响者」，涡城称「波纹士兵」），复刻无门，应雄提出「我变成钟」(第712-714章)。
- 现实线：许家华请应雄喝可乐并为「收保护费」道歉，教他「英雄=喂饱小弟的大哥/戴王冠的王子」；李思维送自行车与报纸王冠宝剑，讲《快乐王子》；应雄言「想当王子但只想自己当——燕子可以飞走」；「刑官」劝他连杀全城两轮以治城病，被判不可行(第715-719章)。
- 约九年后：一队近五万七千颗玉再遭顾禹隐匿，队员揪应雄衣领、王冠落地；顾禹以隐匿武器当众杀人立威、反诬其队「篡位」。随后宣布下轮彻底离开：将以自设的取玉游戏成为道城「人猴」，凭「掌心藏法」作弊（猴可「作弊」）；四年前他已赌死一只人猴、藏起面具。结句问李思维：「你不想成为会『逃脱』的兔吗？」(第719-721章)

## 人物动态
- 新登场：郑应雄（郑英雄） — 泉州八岁小学生，地震身亡；清香「灵嗅」，可闻能力名、情绪乃至想法，过用则流鼻血。
- 新登场：李思维 — 温暖的年轻姐姐，普通大学生；「治愈」；万财死后掌局，守着应雄。
- 新登场：万财 — 传销头子、玉城独裁者；「扩音」；预言三时代，死于自家家规。
- 新登场：顾禹 — 近景魔术师，黑衣长发；「隐匿」；两度藏玉，决意赴道城做「人猴」。
- 新登场：许家华 — 应雄同桌，衣脏味净；地震中救他而死，授「大哥/王子」之道。
- 变化：齐夏 — 苏醒后判若两人，牵涉文巧云、燕知春、「针」与天龙。
- 变化：郑英雄 — 向齐夏半跪；其来道城正是为寻当年那个召唤气味(第689章)。
- 退场：万财 — 被家规公审处决，沦为游荡者；许家华 — 地震中身亡(回忆线)；刘飞 — 被拔河「赌命」处决。

## 伏笔与悬念
- 变质齐夏：灰眼横瞳、「神」的气味、七十年答案、缺一环的计划、命脉之「针」、燕知春、「天龙也该醒了」——郑英雄的目标是否即他？(第688章)
- 道城召唤者：「来找我，无论多少年我都在这里等」，与「显示屏+铜钟」（「我听到了回响」）疑同源(第712-714章)。
- 集齐「玉」触发「重新开始」的大骗局；两座无名之城已全员阵亡(第709章)。
- 「神龙」「刑官」只是地龙地牛，调离即玉城死；应雄当即联想「姐姐也要消失了？」(第687章)
- 《快乐王子》谶语：穷人会捉住燕子、以性命要挟王子永远服务——李思维（燕子）的命运已埋(第717-718章)。
- 「刑官」忠告：毁掉玉城人的正是「记忆」；连杀两轮方能治城；她身上兼有清香与生肖臭味(第717章)。
- 顾禹问李思维是否想成为会「逃脱」的兔——与前列「兔可破坏」不同，疑指另一类兔(第721章)。
- 面试房间面具人提及「列车」(第693章)；生肖皆前参与者，戴面具即成生肖；狗「挑拨」、兔「破坏」、蛇「徇私」、羊「说谎」、猴「作弊」(第721章)。
- 回收：上块「玉城」悬念由地猴作答；郑英雄来道城之目的揭晓(第687、689章)。

## 时间与地点线索
- 双线：现实=道城地猴赌场（承接朔望月赌局之后）；回忆=玉城前后约九年（八岁生命停在地震）。
- 轮回机制：每轮十天，第十日「湮灭」化粉末；回现实约一天半再入局；清香者保留记忆，他人失忆；意外死亡者尸体留存、下轮复活。
- 场景：泉州（教室、家、棋牌室、地震现场）→面试房间（氯气井）→玉城街头→超市负二层仓库→写字楼（负一层保险屋、广场、环形走廊）；现实线小卖部与桥墩。
- 玉城人分「游荡者」与「参与者」；地级游戏唯「刑官」主持，玉城人不涉足。
- 数值：玉目标57,600颗；拔河入场60玉、胜得120玉；清香者统计：辅助209、强化自身126、幻想70余、战斗40余、造物20余。
- 万财预言：权力时代→混乱时代→崩坏时代；顾禹/李思维另提「英雄时代」。

## 本块人物索引
- 齐夏 — 主角；苏醒后灰眼横瞳，断言无人能逃，提及文巧云、燕知春与天龙。
- 郑英雄（郑应雄） — 玉城「城市英雄」，本名应雄；「灵嗅」；本块第一人称叙述者。
- 地猴 — 地级生肖，曾在玉城开赌档，道城现任庄家；道破玉城「神龙」「刑官」真相。
- 陈俊南 — 队友，怒揍变质齐夏。
- 乔家劲 — 队友，在场见证。
- 甜甜 — 队友，在场见证。
- 李思维 — 年轻姐姐，大学生；「治愈」；与顾禹共掌玉城，守护应雄。
- 万财 — 传销头子，玉城独裁者；「扩音」；被自己定的家规处决。
- 顾禹 — 近景魔术师；「隐匿」；两度藏玉阻集齐，将赴道城做「人猴」。
- 许家华 — 应雄同桌；地震中救他而死；教他「大哥与王子」。
- 刘飞 — 家人，求谎报清香事发，被「拔河赌命」处决。
- 赵婶婶（赵姐） — 揭发刘飞的婶婶。
- 方姐 — 同屋婶婶，首轮死于地虎游戏，后以「寒冰」清香再现。
- 胖哥哥（未具名） — 首位外人清香者，能力「惊雷」。
- 兔头人/虎头人/狗头人 — 面试房间主持；虎、狗留氯气中赴死，兔随众人出。
- 龙头人（怪物面具） — 发玉并宣布「十天集五万七千六百颗」者。
- 女牛头人/「刑官」 — 地牛；拔河庄家兼处刑者；劝应雄杀全城两轮。
- 地虎 — 自相残杀游戏的主持生肖(提及)。
- 文巧云 — 道城首领，齐夏问「已经死了吗」(提及)。
- 燕知春 — 齐夏口中另一根「针」(提及)。
- 聂北 — 涡城统治者，在役特种兵，全民皆兵(提及)。
- 钱多多 — 道城智将，顾禹的情报来源(提及)。
- 天龙 — 齐夏口中「该醒了」的存在(提及)。
- 阿嬷 — 许家华常光顾的小卖部老板娘。
