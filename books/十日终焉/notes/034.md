# 块 034(起始章节:第1149章 乡亲们 → 第1183章 中奖者)

## 本块事件
- 极道毁钟小队(老吕、童姨)被围,乔家劲劝阻、陈俊南编「终焉办事处巨钟拆迁」说辞打发追兵;齐夏剖析「乌合之众」只想兵不血刃,给台阶必退(1149-1150)
- 童姨与恋人老吕诀别(极道赴生肖地盘送死);老吕求计,齐夏指点他「先回响,再成为生肖」,去废弃围棋社寻路(1151)
- 邱十六携「门」发现猩红裂缝内的「血肉之城」,拉出一个无脸女生,对方坠入深渊(1152-1153)
- 邱十六进入「对玄武最重要的门」:破庙山村,呼吸到「真实空气」泪下;白九隐瞒「此界可能是假的」(1154)
- 玄武失控:断骆十五之颈、重伤罗十一,王八「巨化」断后;儿时玄武「萱子」进破庙烤玉米芯(1155-1156)
- 萱子自述:吴家村守庙人之女,娘饿死于饥荒,村民砸菩萨抓她毒打却怕枪毙;「不可自杀,只可被杀,命是菩萨的」,求邱十六杀她(1157-1159)
- 掐杀萱子触发两个玄武「同频」:玄武扯断王八手臂、撕落邱十六右臂;李警官「探囊」取眼取心皆败(1159-1160)
- 姜十设「接班人」计:哨声加密传令,全员信念集于己身,假扮比菩萨更强的守庙接替者(1161)
- 王八被捏碎心脏而死;姜十连演「心来、刺来、叶子来、风来、雨来」,白九液化骆十五尸体降血雨;玄武动摇,交出后背眼球,「我的心丢了」,碳化而亡;白虎宣告「吴萱,你解放了」(1162-1165)
- 玄武忆起:白虎本名胡亦然,曾教她「放下兵器,享受虐杀」「大胆」等吓人台词;青龙嫌她「理智太多」夺走一半,并令以「疯长」改造她——记忆戛然而止(1164-1165)
- 姜十「不灭」油尽灯枯,喊「不要让我孤单的死」焚身而亡;击杀玄武成功:死三(骆十五、王八、姜十)消失一(邱十六);白虎泄朱雀弱点——三颗眼球含口中,是「疯矛」;宋七宣布以全员之命杀朱雀(1165-1166)
- 天级互相推责;失智青龙(灵闻失效)强令天蛇原址原样重建巨钟、再造「拿走全部理智」的玄武(1167-1168)
- 齐夏在极乐钱庄打开保险柜(密码401087)取得旋转的「门」;看破白羊阳谋——多用「生生不息」就近疯一分,白羊便可成真重生;自称「注定死在此,将与天龙乘列车去远方」(1169-1170)
- 云瑶循「强运」寻来;齐夏摊牌今晚潜入列车带众人逃离;章晨泽决意「回去面对」,甜甜求死于列车(1171)
- 极道八队就位:白蛇不知情后默许燕知春;江若雪砸桌造「裂缝」强拖地猴(申猴)下水;老孙在辰龙空地扑空,被认作东北老乡的地虎收留(1172-1175)
- 天堂口被百余人围殴,楚天秋与地鼠赌「天意」;忆起天堂口源于乔家劲草创的「堂口」(「天」字是他自己加的);吞四颗眼球「以一当百」;文巧云替他挡铁管而死,拒绝他用最后一颗「生生不息」复活(1176-1180)
- 魏杨、秦丁冬率上千原住民破围;地鼠门开,楚天秋携张山上车,小眼镜、李香玲留下,小眼镜要给老吕收尸(1181-1182)
- 青龙以「夺心魄」查林檎脑海竟一无所获;周末处朱雀赤羽落地,披羽毛披风者现身,周末传音各队「各位,你们安全了」(1183)

- 新登场/首次揭示:萱子(儿时玄武,右眼藏双瞳的守庙人小姑娘);人猴(地虎女徒弟,受「鼠」之托接应老孙队);魏杨、秦丁冬、张山、金元勋、小眼镜、李香玲、文巧云、楚天秋、老邓、潇潇、林檎等本块新出场;胡亦然/吴萱/小严——白虎、玄武、朱雀本名借回忆揭开(神兽无名字,提名即犯规)
